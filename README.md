# IoT LAB 1 
# ESP32 to ThingSpeak Temperature & Humidity Monitoring

## Project Description
This project demonstrates how to read live temperature and humidity data using an **ESP32** microcontroller and a **DHT22** sensor, and securely transmit the data to the **ThingSpeak** cloud platform every 20 seconds. The data is visualized publicly through real-time charts.
